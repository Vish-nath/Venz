# Snake Triage Backend

Secure Node.js & Express REST API for the Snake Triage System.

## Features
- **Helmet**: Hardened HTTP security headers.
- **CORS**: Configured origin protection.
- **Request Logging**: Morgan HTTP logger.
- **Triage API**: Endpoints for medical triage and incident analysis.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the server:
   ```bash
   node src/server.js
   ```
